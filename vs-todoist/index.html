On price: Todoist's free tier covers basic task lists, but reminders — genuinely core to getting things done — sit behind Pro. Owning dither on your phone and desktop costs less up front than a single year of Todoist Pro, and there's no second year, or fifth.

Where Todoist still has the edge

Being a hosted, account-based service isn't only a downside — it buys real things dither doesn't offer.

A real web app

Todoist runs in any browser with no install. dither is a native app on every platform — no web version, by design, so far.

Team & collaboration features

Shared projects, assigning tasks to other people, and Business-tier admin tools are built for teams. dither is a single-user, local-first app — it isn't trying to be a team tool.

A genuinely free tier

If you only need basic lists and can live without reminders, Todoist's free plan costs nothing, forever — dither has a free trial, not a free tier.

Wide third-party integrations

Zapier, IFTTT, Alexa, and dozens of app integrations exist for Todoist thanks to its cloud API and user base. dither's local-first, no-account design doesn't offer an equivalent integration surface.
